# Panel Catastral Inteligente (demo Streamlit)

Demostración del Módulo V — *Machine Learning Aplicado al Espacio Geográfico* (CNR El Salvador).
Facilitadora: Jessica Martínez · doulus.jefis@gmail.com

App de ejemplo con datos 100 % sintéticos: mapa de valores, valuador con intervalo de confianza,
semáforo de alertas catastrales, validación aleatoria vs. espacial y carga de CSV propio.

## Archivos
- `app.py` — toda la aplicación (un solo archivo)
- `requirements.txt` — librerías que Streamlit Cloud instala
- `.streamlit/config.toml` — colores del tema (opcional)

## Ejecutar en tu computadora
```
pip install -r requirements.txt
streamlit run app.py
```

## Publicar
Sube estos archivos a un repositorio público de GitHub y créala en https://share.streamlit.io
indicando `app.py` como archivo principal.
